# invest-perf

用來計算台股投資績效的簡易網站

## 介紹

- 使用者可以自己新增交易紀錄和股利紀錄來得到計算後的報酬率等等資訊
- 資料完全儲存在瀏覽器的本地空間裡，並不會上傳到某個遠端的機器
- 使用到臺灣證券交易所提供的 OpenAPI、官方網站和資訊系統的 API
  - 在呼叫的時候會刻意節流以避免突破使用頻率上限
  - 使用了 corsproxy.io 來規避 CORS 問題

## 背景

這只是我為了體驗看看 vibe coding 而興起的一個專案。
起初我使用 [OpenCode](https://opencode.ai) 來快速幫我生成前端，並且幫我設計投資績效可以呈現的內容。
我覺得體驗很好，他可以產生比我預想還要好的成品出來。
不過大概是因為免費模型不是很聰明，有些小細節需要我親自處理，還有公式計算的部份，我也花了一些時間親自設計。
到了要收尾的時候，我也試用了 [Codex](https://openai.com/codex/) 來幫我修正年度報酬率和年度累積損益的公式。
GPT 5.4 的模型果然聰明很多，生成的程式碼品質很好，修正後的內容我也覺得比較有道理。
為了要確保成品的品質，最後我還是有審視程式碼，可能不能算完全的 vibe coding 了，但基本上整個專案我都是放手讓 AI 代理來替我完成，整體而言我覺得這是很好的體驗。
